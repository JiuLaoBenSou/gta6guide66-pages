GTA 6 怎麼手動存檔？如何回到任務前

接下想重玩的任務前另存一格，離開前再到讀檔清單核對時間。

建立手動存檔

  1. 在自由探索時，按 PS5 的 Options 鍵或 Xbox 的選單鍵暫停。選擇 Game → Save Game。
  2. 進入任務前挑一格空白欄位。存好後開啟 Load Game，確認清單裡的日期和時間。

存檔選項反灰時

部分任務中途無法手動存檔。回到自由探索後，再開啟暫停選單存檔。

回到已完成任務之前

首發版本沒有可重玩已完成任務的選單。讀取舊檔可能覆蓋自動存檔，建議先把目前進度另存一格，再讀取保留的任務前存檔。
