GTA 6 怎麼手動存檔？關卡重來與自動存檔差異

自由探索時，從暫停選單的 Game 進入 Save Game。關鍵任務前另存一格，離開前確認新存檔出現在清單。

另存一個可回到任務前的進度

  1. 回到自由探索，打開暫停選單。切到 Game → Save Game。
  2. 挑空白位置，確認儲存後回到清單檢查進度與時間。若選項暫時不可用，先完成正在進行的任務段落並回到可操作的自由探索。
  3. 打算回頭再玩時，使用 Load Game 選指定手動存檔。切換回舊進度後，讓新遊玩的進度另外存一格。

任務的檢查點用於當次重試。首發實機攻略記載有 15 格手動存檔與一格自動存檔，並指出沒有獨立的任務重玩選單。
