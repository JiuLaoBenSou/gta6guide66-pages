Provas de Top Fun Drones no GTA 6

Vença uma prova em cada local de Top Fun para o troféu. Para os 100% do Modo História, termine as três provas em cada um dos 14 locais.

Como liberar as três provas

  1. Chegue perto do local até aparecer o ícone azul de drone. Selecione em Mapa → Atividades → Top Fun Drones. Para Dalton Island, leve um barco ou aeronave.
  2. Inicie a prova 1 e bata o tempo-alvo. Faça o mesmo na prova 2 para abrir a última. Se continuar errando a meta, passe pelos espaços estreitos com precisão antes de empurrar o analógico todo para a frente nas retas.
  3. Termine a prova 3 com qualquer tempo para contar nos 100%. Confira Progresso → Atividades → Top Fun Drones antes de sair. Você deve ter concluído as três provas em cada local, duas abaixo do tempo-alvo.
