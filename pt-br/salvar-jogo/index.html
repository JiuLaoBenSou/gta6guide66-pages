Como salvar o jogo no GTA 6 e voltar a uma missão

Na exploração livre, abra Pausa → Game → Save Game. Use um espaço separado antes de uma missão que você queira jogar de novo.

Mantenha um salvamento anterior à missão

  1. Na exploração livre, pause com Options no PS5 ou Menu no Xbox. Entre em Game e selecione Save Game.
  2. Escolha um dos 15 espaços de salvamento manual. Use um espaço vazio para o começo de um capítulo ou para uma missão que você queira revisitar.
  3. Antes de sair, abra Load Game e confirme que o salvamento manual esperado está na lista. Volte após a verificação ou selecione esse espaço quando quiser retornar à missão.

Como voltar a uma missão concluída

Guias do lançamento relatam que o Modo História não tem um menu para repetir missões. Durante uma missão, é possível reiniciar a partir de um ponto de controle.

Se a opção de salvar estiver bloqueada

Tente novamente na exploração livre, depois que a missão ou atividade devolver o controle. Se ativou um código de trapaça, reinicie o jogo e carregue o salvamento manual que fez antes. Reiniciar pelo ponto de controle pode desfazer parte da missão atual. Um salvamento manual anterior reverte todo o progresso para o estado salvo.

Quando usar o salvamento automático

O guia da versão de lançamento registra um único espaço de salvamento automático. Carregar um salvamento manual anterior e continuar jogando pode substituir o automático. Use espaços manuais separados, que você reconheça pelo progresso exibido. Se Tá nervoso? Vai pescar parecer concluída, mas o jogo voltar para um ponto anterior na próxima vez que abrir, confira o objetivo e a lista de salvamentos antes de sair novamente. Ainda não há um intervalo de salvamento automático confirmado para todas as atividades secundárias.
