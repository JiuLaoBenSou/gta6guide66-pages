Locais de saltos acrobáticos no GTA 6

Encontre os 130 saltos terrestres de Leonida. Depois de aterrissar, confira o mapa para ver se o salto contou para Cunning Stunts e os 100% do Modo História.

O que conta para 100%?

Aterrisse e confira se o jogo marcou o salto como concluído. O desafio do marcador é um objetivo extra. Dá para deixar as cambalhotas, os veículos especiais e as exigências de rádio para depois. Para Cunning Stunts, conclua 250 manobras. Para 100% no Modo História, conclua 300. Os dois totais somam saltos terrestres e 267 manobras aéreas e de paraquedas.

O código Unlimited Nitrous tem um requisito separado de 50 saltos terrestres concluídos. Deixe os códigos desligados enquanto faz progresso que quer salvar.

Confira se a manobra contou

  1. Abra Progresso → Atividades → Manobras e selecione a categoria. Em Stunt Jumps (saltos acrobáticos), pressione o analógico direito para conferir os números por condado.
  2. No mapa de pausa, escolha Exploração → Pontos de manobras para ver os nomes. Roxo indica descoberto e branco indica concluído. Confira a entrada antes de repetir um salto que já completou.

Mile Zero Air Station Southeast

  1. Dirija até Goose Key. Na bifurcação a leste da base aérea, pegue o caminho de baixo para chegar à cerca sudeste.
  2. Depois das barricadas, alinhe o veículo com o monte de terra voltado para a cerca. Deixe espaço para acelerar e aterrisse dentro do aeródromo. Consulte o guia de acesso a Mile Zero antes de entrar na área restrita.

Pares de saltos nas Keys

  • Saltrock Bridge East / Saltrock Bridge West. Procure as duas rampas com nome na travessia antiga entre Abismo Key e Goose Key.
  • Key Lento Bridge East / Key Lento Bridge West. Procure na travessia antiga entre Abismo Key e Key Lento. Use os nomes no mapa para distinguir os dois pontos de salto.

Para tentar o bônus de uma ponte, complete as duas metades em sequência. Para o contador de progresso, confira os marcadores um por um.
