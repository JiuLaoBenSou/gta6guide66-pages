GTA 6 수동 저장과 이전 임무로 돌아가는 방법

임무를 시작하기 전에 별도 슬롯에 수동으로 저장하고 불러오기 목록에서 확인하세요.

임무 시작 전 저장해 두기

  1. 자유 이동 중 PS5의 Options 버튼이나 Xbox의 메뉴 버튼으로 일시 정지하세요. Game → Save Game을 선택합니다.
  2. 수동 저장 슬롯 15개 중 하나를 고릅니다. 다시 플레이하고 싶은 임무나 챕터의 시작 지점은 빈 슬롯에 따로 저장하세요.
  3. 게임을 종료하기 전에 Load Game에서 방금 저장한 파일이 목록에 있는지 확인하세요. 같은 지점으로 돌아가려면 해당 파일을 불러옵니다.

이전 임무로 돌아가는 방법

출시 버전 공략에서는 별도의 임무 다시 플레이 메뉴가 확인되지 않았습니다. 진행 중인 임무에서 체크포인트를 다시 시작할 수 있습니다.

수동 저장을 선택할 수 없을 때

임무나 활동이 끝나 자유 이동이 가능해지면 다시 시도하세요. 치트를 사용했다면 게임을 재시작하고 적용 이전에 만든 수동 저장을 불러오세요. 체크포인트는 현재 임무 일부를 되돌리고 수동 저장은 게임 전체 상태를 되돌립니다.

자동 저장을 사용할 때

출시 버전에서는 자동 저장 슬롯이 하나입니다. 이전 수동 저장을 불러온 뒤 진행하면 기존 자동 저장이 덮어써질 수 있으므로 슬롯을 따로 사용하세요. Gone Fishing 완료 후 재접속했는데 이전 지점으로 돌아갔다면 종료 전 목표 표시와 저장 목록을 확인하세요. 보조 활동의 공통 자동 저장 시점은 확인되지 않았습니다.
