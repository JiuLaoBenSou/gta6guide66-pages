GTA 6 PS5·Xbox 치트 코드 19종과 입력 방법

GTA 6 스토리 모드 치트 19종의 버튼 입력 순서, 게임 내 휴대전화 사용법과 해제 조건을 확인하세요.

치트 입력 방법캐릭터전투이동 수단날씨와 필터코드가 작동하지 않는 경우

치트 입력 방법

  1. 메인 스토리를 완료하세요. 자유 모드에서 방향키 위를 눌러 게임 내 휴대전화를 여세요.
  2. PS5에서는 L1을 누른 채 R1을 누르세요. Xbox에서는 LB를 누른 채 RB를 누르세요.
  3. 방향키를 표시된 순서대로 누르세요. 입력 순서는 두 콘솔에서 같습니다.

치트를 활성화하면 현재 세션에서 저장, 트로피, 도전 과제 달성이 제한됩니다. 사용 전에 별도 슬롯에 수동으로 저장하세요. 정상 상태로 돌아가려면 게임을 재시작하고 치트를 쓰기 전 저장 파일을 불러오세요.

낙하 피해 무효화 해제 방법

PowerPyx와 3DM에 따르면 40피트 높이에서 떨어지고 20회 살아남아야 합니다. 스토리를 완료한 뒤 Progress → Cheats에서 확인하세요. 이 효과의 방향키 입력은 확인되지 않았습니다.

코드가 작동하지 않는 경우

스토리를 완료했는지, 해당 치트를 해제했는지, 자유 모드에 있는지 확인하세요. 숄더 버튼을 누르기 전에 휴대전화 홈 화면을 연 뒤 방향키 순서를 처음부터 입력하세요. 임무의 네 자리 비밀번호는 현장 키패드에 입력합니다.
