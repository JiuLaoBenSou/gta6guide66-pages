GTA 6 door codes

Use 0420 at the Lab Fees lab, 7700 at Brian’s Lock Up, or 2727 at the ’74 Vamos garage.

Lab Fees · Moonstone Boutique

Lab Fees lab door

Keypad code 0420

Use the keypad behind the shop counter, beside the lab entrance. Enter all four digits, including the zero. The keypad’s Notes panel can also show the code after you learn it.

Brian’s Lock Up

Keypad code 7700

Follow the delivery marker to the Isla Tropical private club. Look for the lockup near the fish mural. Use the keypad at the lockup entrance.

How to find a robbery safe code

For randomized robbery safes, look for the combination from your current run. Some named locations have their own fixed combinations.

  1. Press both sticks (L3 + R3 on PS5, or click both sticks on Xbox) to use Focus. Inspect nearby notes or other clues inside the location.
  2. Interact with the safe once you have its combination. Check the lower-right corner for the code prompt, then enter the displayed digits.
