GTA6 怎么设置中文？简体、繁体字幕和界面字号

在游戏的 UI 页面找语言选项，再到同一页的字幕区域开启字幕和调整大小。PS5 港区支持说明列出了简体和繁体中文文本。

看不懂英文菜单时怎么找

  1. PS5 按 Options 打开暂停菜单。进入 Photo Studio 下方的 Settings。
  2. 按 L1 或 R1 切换到 UI 标签，在 Scaling & Readability 里找到第一项 Language，左右切到简体中文或繁体中文。
  3. 如果语言列表里没有中文，对照自己所购版本的商店页面查屏幕语言。帮助页里的支持列表对应特定地区，核对时留意地区和主机。

开字幕和把字调大

在同一标签的 Subtitles & Captions 中调字幕范围和字号。遇到亮色背景看不清时，把字幕背景打开。希望操作提示也大一点，可以调 UI Text Size。

港区支持表只给英文标注语音。想回看刚才漏听的台词或目标，可以打开暂停菜单的 Brief 标签。
