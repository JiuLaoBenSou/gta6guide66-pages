GTA 6 道路特技跳跃地点

找齐 Leonida 各处的 130 个道路跳点。落地后查看地图条目，确认跳跃是否计入 Cunning Stunts 和故事模式 100%。

哪些跳跃计入 100%

完成道路跳跃并成功落地后，查看游戏是否将其标记为已完成。地图标记上的挑战属于附加目标。翻转、指定车辆和电台要求都可以留到以后。Cunning Stunts 要完成 250 项特技，故事模式 100% 要完成 300 项。两项总进度都会合计道路跳跃与267 项飞行和跳伞特技。

作弊码 Unlimited Nitrous 另需完成 50 个道路跳跃。想保留进度时，先关闭作弊码再刷进度。

检查特技是否计入进度

  1. 打开进度 → 活动 → 特技并选择类别。在Stunt Jumps（特技跳跃）中按下右摇杆查看各县的计数。
  2. 暂停地图中选择探索 → 特技地点，查看带名称的标记。紫色代表已发现，白色代表已完成。重复已落地的跳跃前先核对条目。

Mile Zero Air Station Southeast

  1. 开车到 Goose Key。在航空站东侧的岔路选下面那条，开往东南围栏。
  2. 通过路障后，把车对准朝着围栏的土坡。留出加速距离，起跳后落在机场内。进入限制区前查看Mile Zero 进入路线。

群岛上的成对跳点

  • Saltrock Bridge East / Saltrock Bridge West. 在 Abismo Key 与 Goose Key 之间的旧通道上，找两个带名称的起跳点。
  • Key Lento Bridge East / Key Lento Bridge West. 搜索 Abismo Key 至 Key Lento 的旧通道。用地图标记名称区分两个起跳点。

想试桥上的额外挑战，连续完成两段。核对完成计数时，分别查看两个标记。
