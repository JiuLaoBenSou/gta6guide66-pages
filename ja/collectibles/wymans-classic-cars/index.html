ワイマン（Wyman）のクラシックカー集め

第2章でドミネーター・バギーを受け取ると、アルティメットエディションのワイマンの依頼が始まります。レオナイダ各地で廃車15台をスキャンして4台を復元すると、最後の連絡で’72 Deviantを受け取れます。

解放条件TransgressorRiataMamba GTReynolds Kit CarDeviant

ワイマンの車探しを解放する

  1. 「スリルビリー」を終えたら、紫色のドミネーター・バギーの目標を探します。ワトソン湾周辺にあるParadise RV Parkの車庫へ行き、バギーを受け取ります。
  2. ワイマンからメッセージが届いたら、地図の Map → Exploration → Find Cars for Wyman を開き、依頼中の車種を追跡します。徒歩で方向キー上を長押ししてWAiNKを開き、廃車に照準を合わせ、PS5はR1、XboxはRBでスキャンします。
  3. その車種の最後の廃車をスキャンしたら、BuckMeにワイマンから復元費用GTA$1,500の請求が届いているか確認します。支払い後、Wマーカーで車を受け取り、自分の車庫に保管するかPay ’n’ Sprayで登録します。

’67 Transgressor · Port Gellhorn

  1. Tanglewood Lane. Sarena’s Bargain Storeから北のトレーラーパークへ進みます。別ルートはUS-9沿いのMcCarthy’s Fresh Fruit & Vegの円形車道です。店の右側を回ってトレーラーとブタを通り過ぎると、日陰のコンクリート台に廃車があります。
  2. Gellhorn Avenue. Wasteland Off-Roadの北西で庭にヒマワリのある青い家を探します。Brooks Boatworksからなら大通りを北東へ進み、テニスコートを通過します。家の右側を通り、ピックアップトラックの先の開いた物置を調べます。
  3. Dirt Merchantsの南. 店の横の未舗装路を小さなトレーラーパークまで進みます。前にキャンピングカーが停まっている木造の建物を探します。廃車は建物裏の壊れた柵のそばです。Dunkの強盗情報が有効なら、近くの目印として使えます。

以下の3ルートはコミュニティの公開記録に基づきます。出発前に、廃車が追跡中のワイマンの依頼と一致するか確認してください。

’70 Riata · 南部の3地点

  1. Key Lento. Sunbelt Highway脇の警察の保管所から、水辺側の高床の家へ渡ります。家の下にある水上バイク用トレーラーのそばを調べます。
  2. Southwind. Xeroのガソリンスタンドから水辺へ向かう脇道に入ります。突き当たりの開放型車庫を調べます。
  3. Shoeless Keys. Hamletから南へ進み、Old Fort Roadに入ります。廃業したガソリンスタンド裏の屋根付きスペースを調べます。

’64 Mamba GT · 車庫2か所と水辺2か所

  1. Leonida State Prisonの北. Gruppe Sechsの施設を交差点の目印にします。施設の向かいの道を上り、住宅から離れた車庫を調べます。
  2. Ambrosia. 虹色のTiny Frankの看板の下にあるXeroを探します。トラクター置き場を過ぎて店の裏の道に入り、緑色のトレーラーの横の小さな車庫を調べます。
  3. Thrillbilly Mud Club. レース場の看板の下から入り、左の分岐から未舗装の周回路へ。コース左側の池の中を調べます。
  4. Moreau北部. Bonanzaの東側付近で壊れた橋を探し、橋のがれきの下の水中を調べます。

Reynolds Kit Car · レオナイダの廃車5台

  1. Salton. 7th Avenue Garage付近の緑色の立体駐車場の西にある、オレンジと青のWillie’s Service Centerを探します。作業場が閉まっている場合は側面の入口からインタラクトします。
  2. Casanova Island. 北側の道を空き地まで進みます。そのすぐ左の敷地で門のある車道を調べます。
  3. Wild Hog Point. Port Gellhorn西側の滑走路の端から砂道をたどり、浜のコンテナへ。1つだけあるオレンジ色のコンテナを、ゲーム内のアングルグラインダーで開けます。
  4. Watson Bay. Seabell Avenueから、水辺のモーテルの向かいにあるDonnie’s Auto Repairへ。作業場の裏を調べます。
  5. Capri. 北西の突端に向かう道で、工事現場の向かいを探します。倒れたコーンとごみ箱がある邸宅を目印にし、木の外装がある車庫まで車道を進みます。

’72 Deviant · ワイマンの最後の電話を待つ

復元した4台をすべて受け取ったら、ゲーム内で時間を進めます。ワイマンから電話が来たらBuckMeを確認し、最後の請求が届いていれば支払います。Wマーカーに向かい、納屋の扉を操作して受け取りを始めます。Progress → Collections → Exploration → Wyman’s Cars で5台を確認できます。これらの任意の依頼はストーリーモードの達成率100％に加算される場合があります。

ワイマンがStarlet Motelで作業を続けているとき

ルシアで Car Trouble? が表示されたら、モーテルでの別の調整イベントです。PS5ではワイマンに向けてL2を長押しし、×ボタンで選びます。運転席でR2を押してエンジンをかけ、各ラウンドで針をメーターのピンク色の範囲に合わせます。最終ラウンドはワイマンの合図に従ってアクセルを踏み続けます。
