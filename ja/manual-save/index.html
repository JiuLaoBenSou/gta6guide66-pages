GTA6の手動セーブとミッション前に戻る方法

自由行動中にポーズメニューから「Game → Save Game」を開きます。後からプレイし直したいミッションの前に、別のスロットへ保存しましょう。

ミッション前のセーブを残す

  1. 自由行動中に、PS5のOPTIONSボタンまたはXboxのメニューボタンでポーズ画面を開きます。Game → Save Gameを選びます。
  2. 15個ある手動セーブスロットのうち1つを選びます。チャプター開始時や後からプレイし直したいミッションの前には、新しいスロットを使います。
  3. ゲームを終了する前にLoad Gameを開き、目的の手動セーブが一覧にあることを確認します。確認後はそのまま戻り、ミッション前に戻りたいときにこのスロットを選びます。

クリアしたミッションに戻りたいとき

発売時点の攻略情報によると、ストーリーモードにミッション再プレイ専用のメニューはありません。ミッションの途中なら、プレイ中にチェックポイントから再開できます。

セーブ項目がグレーで選べないとき

ミッションやアクティビティが終わって自由行動に戻ったら、再度試してください。チートを有効にした場合は、ゲームを再起動して事前に作った手動セーブをロードします。チェックポイントの再開では現在のミッションの一部が巻き戻り、以前の手動セーブを読むとゲーム全体が保存時点まで戻ります。

オートセーブを使うとき

発売時点の攻略情報ではオートセーブ枠は1つです。古い手動セーブを読み込んで続けると、そのオートセーブが上書きされる場合があります。表示される進行状況から区別できるよう、手動セーブは別のスロットに分けてください。ちょっとした釣りを終えたつもりでも、次回起動時に進行が戻っていたら、次に終了する前に目標とセーブ一覧を確認します。サイドアクティビティの共通オートセーブ間隔はまだ確認されていません。
