GTA 6: Tür- und Tresorcodes für Labor, Lager und Vamos

Hier gehören 0420, 7700 und 2727 hin. So findest du außerdem feste Codes und Hinweise für wechselnde Tresorkombinationen.

Labortür bei Lab Fees · 0420Brians Lager · 7700Garage für Moses’ ’74 Declasse Vamos · 2727Weitere feste CodesDen Code eines Tresors beim Überfall finden

Labortür bei Lab Fees

Code für das Tastenfeld 0420

Geh in der Moonstone Boutique hinter den Tresen zum Laboreingang. Gib 0420 einschließlich der führenden Null ein. Wenn du den Code bereits kennst, findest du ihn auch in den Notizen am Tastenfeld.

Brians Lager

Code für das Tastenfeld 7700

Folge dem Abgabemarker zum Privatclub auf Isla Tropical. Das Tastenfeld findest du am Lagereingang in der Nähe des Fisch-Wandbilds.

Garage für Moses’ ’74 Declasse Vamos

Code für das Tastenfeld 2727

Fahre in Kapitel 2 beim Abholauftrag nach Grayson. Der Vamos steht in der Garage am Wohnwagen, in dem gefeiert wird. Dort steht der Hinweis auf 2727. Gib den Code an der Seitentür der Garage ein.

Den Code eines Tresors beim Überfall finden

Einige Kombinationen wechseln. Suche bei diesen Tresoren nach dem Hinweis in deinem aktuellen Durchlauf.

  1. Drücke L3 und R3 auf PS5 oder beide Sticks auf Xbox gleichzeitig. Nutze den Fokus und prüfe Zettel, den Computer oder andere Hinweise in der Nähe.
  2. Sobald du den Code hast, geh zum Tresor und gib die Ziffern über die angezeigte Aktion ein.
