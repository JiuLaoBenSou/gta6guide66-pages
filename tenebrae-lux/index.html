GTA 6 Tenebrae Lux walkthrough

Tenebrae Lux is a JoySystem game inside GTA 6. Clear its four main puzzles from the beach to the lighthouse. Layouts and answers can change, so use the clues in your own run.

Start a full run

At Jason’s residence, use the JoySystem console, open Games, choose the lighthouse thumbnail for Tenebrae Lux and select New Game. The opening board also appears in Cal’s Feng Shui mission. Return to a home console in free roam for the full route.

See all four arcade and home console games

1. Clear the three beach boards

  1. Face inland from the beach and look for the lit shacks to the left. There are two required boards in the first shack and one in the next. Clear all three to open the bunker.
  2. A movable piece slides in a straight line until blocked or it reaches an edge. At its stopping square it interacts only with neighbors above, below, left and right.
  3. Use pointed pyramids to remove the low, dotted tiles. A pyramid survives that interaction. When a pyramid stops beside a tall, tiered stack, or the stack stops beside the pyramid, both disappear. Keep enough pyramids for the dotted tiles first. If the remaining pieces cannot meet, leave that board and return to reset it.

2. Get the bunker phone code

  1. Use the stairs and door beside the phone to repeat the room. Compare visits and record the object that changes and the October date on the calendar.
  2. Get one digit for each date. If a clue gives several digits, add them and repeat until one remains. Sort the results by October 11, 14, 20, 23, 27 and 30. Dial the six digits in that order, press #, then go back up the stairs after the call succeeds.

3. Cross the Eternal March bridge

  1. Read the plaque by the ruins and write down the object clues from top to bottom. Skip the title. Where one line names two objects, keep their order. A rest line with no object usually adds nothing. Use each of the seven objects once.
  2. Find the glyphs near the matching objects. Look for a trophy for gold, a tree for forest, a brazier for heat, a fountain for drink or water, an earthen pot for earth, a sundial for sun and a sculpture for moon.
  3. On the bridge, choose the tile with the next matching symbol in each row. If you trigger a reset, read the new verse and check the symbols again. Cross the bridge and head up toward the lighthouse.

If the poem links an object to sleep or slumber, keep its ordinary mention if it appears elsewhere. If that is its only mention, check for a rest line. An earlier rest line leaves the clue in place. A later rest line takes the clue at its beginning. If there is no rest line, put that object last.

4. Pick the lighthouse doors

Wait for the shadow figures to choose their doors. Ignore the ones they use and any marked out of order. For each remaining door, count its gap from the nearest door a figure used. Pick the one with the largest gap. If two tie, use the door farther from the figures overall. For example, if one figure takes door 6 and door 1 is open, head to door 1. Check again on every floor. The last correct door takes you to the credits and can earn Stick Fiddler if you have yet to unlock it.

Optional ending

After the main credits, return to the Eternal March ruins and interact with the burning memorial to begin the optional ending. Look for manuscript pages and moon-phase clues. The door at the end of the pier is part of that route.
