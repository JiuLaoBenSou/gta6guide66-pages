GTA 6 Stick Ups and store locations

Find a store in Map → Robberies → Stick Ups. Story Mode 100% needs 50 different completed jobs out of 91 tracked by the game. The 24 stops below give you places to start.

Finish a store job24 store stops100% and challenges

Finish a store job

  1. Open Robberies → Stick Ups in the pause map. Select a card in a revealed area. If you are following Chapter 2, Girl’s Trip introduces the store interaction, and Port Gellhorn has several nearby stops.
  2. At the counter, use the game’s Threaten prompt and collect the cash once the clerk empties the register.
  3. If the store has a marked safe, follow the prompt for its combination. Some game branches show a staff interaction or an office clue. Use the back office only when the game shows a relevant prompt.
  4. After the in-game wanted level is clear, reopen the job card and check which objectives registered. When the same shop can be repeated, choose a different task card to advance the unique-location count.

Find 24 store stops

The labels show the available evidence. A map card means the source reports seeing the named Stick Up. A recorded run shows a cash pickup. Nearby stops come from the Port Gellhorn route. For the last two groups, check the Stick Ups filter for credit in your save before counting the stop.

Mariana County

  • Xero Food Mart · Southwind · Register run recorded

    Choose the Southwind branch. The recorded run used the gas-station food mart there.

  • One Stop Liquor · Key Lento · Register run recorded

    Use the Key Lento branch at the Arrow station. Check the shop sign before going in.

  • Key Lento Mini Mart · Register run recorded

    Look for the Mini Mart on Key Lento. This is a separate stop from One Stop Liquor and 247.

  • Jim’s Mini Mart · Map card reported

    Find the named Mini Mart in the Keys. The map lists it separately from Key Lento Mini Mart.

  • Xero Food Mart · Grassrivers · Map card reported

    More than one Xero shop is mapped in Grassrivers. Use the Stick Ups filter to find the eligible branch in your save.

Kelly County · Port Gellhorn

  • Uncle Jack’s Liquor · Port Gellhorn · Map card reported

    Start at Starlet Motel and select the Port Gellhorn branch. Bayside and Tequesta have different Uncle Jack’s shops.

  • Sarena’s Bargain Store · Register run recorded

    Look near Starlet Motel. The recorded run includes the counter; check your in-game card for completion.

  • 247 · Port Gellhorn · Nearby guide stop

    Look near the motel. Match the Port Gellhorn label to avoid the other 247 stores.

  • Dale’s Shopwell · Map card reported

    Use the named store near the motel. The shop has a separate card from 247.

  • Hank’s Waffles · Map card reported

    Select the diner in the Port Gellhorn area. The in-game interaction menu can differ from the liquor shops.

  • Eager Beaver Express · Nearby guide stop

    Select the Express storefront near the motel. The fuel-pump icon is a separate map category.

  • Alpha Convenience Store · Gellhorn · Map card reported

    Choose the Gellhorn shop. Belville also has an Alpha branch.

  • Taco Bomb · Gellhorn · Map card reported

    Match the port-area Taco Bomb. The game has other branches in Belville, Waning Sands and West Kalaga.

  • Bargain World · Port Gellhorn · Register run recorded

    A filmed run took cash at the register. Check the Stick Ups map filter before counting it in a 100% route.

Vice-Dale County · Vice City

  • Xero Food Mart · Rockridge · Map card reported

    Select the Rockridge branch in the game’s job list.

  • Xero Food Mart · Crosstown · Map card reported

    Select the Crosstown branch, separate from La Perle and Rockridge.

  • Xero Food Mart · La Perle · Map card reported

    Search the La Perle part of the Stick Ups list for the Xero branch.

  • Blessed Food Market · Map card reported

    Look up the full shop name in Vice City’s grocery markers.

  • XYZ Market · Map card reported

    Use the XYZ Market label for this Vice City corner shop.

  • Zak’s Liquor · Map card reported

    Find the liquor-store map card with Zak’s name in Vice-Dale.

  • Hugo’s Quick-Mart · Map card reported

    Use the Quick-Mart card in Vice-Dale and check the station storefront.

  • Palmis Liquor · La Perle · Map card reported

    Find the shop on Del Rio Boulevard. Its storefront Stick Up and the rear-room Cigar Import Front are separate jobs.

Leonard County · Belville

  • 247 · Belville · Map card reported

    Select the Belville branch in the Stick Ups list.

  • Xero Food Mart · Belville · Map card reported

    Find the Xero-branded food mart in Belville, separate from the local 247.

50 for 100% and the timed challenges

  • Story Mode 100%: Finish 50 different map jobs. Some ordinary convenience-store, fast-food and liquor pins have no verified Stick Up card. Use the Robberies filter when picking the remaining stops.
  • Stick Ups challenge: Finish three in one day without dying or getting arrested.
  • Stick Up Spree: Finish two stores per county under 20 minutes, with no death or arrest. That means ten stores across Mariana, Kelly, Vice-Dale, Leonard and Lummox. Reveal the map and pick two game-listed shops per county before starting. This guide has no verified Lummox route yet.

For separate map categories, see pawn shops and jewelers, Payday Loans or gang operations.
