Emplacements des sauts acrobatiques dans GTA 6

Trouvez les 130 sauts routiers de Leonida. Après l’atterrissage, vérifiez le marqueur pour savoir si le saut compte pour Cunning Stunts et les 100 % du mode Histoire.

Qu’est-ce qui compte pour les 100 % ?

Atterrissez puis vérifiez que le jeu a validé le saut. Le défi du marqueur est un objectif supplémentaire. Gardez les figures, véhicules spéciaux et conditions de radio pour plus tard. Il faut 250 cascades pour Cunning Stunts, et 300 pour les 100 % du mode Histoire. Les deux totaux combinent sauts routiers et 267 cascades aériennes et en parachute.

Le code Unlimited Nitrous demande séparément 50 sauts routiers terminés. Laissez les codes désactivés tant que vous voulez enregistrer vos progrès.

Vérifier la validation d’une cascade

  1. Ouvrez Progression → Activités → Cascades et choisissez la catégorie. Dans Stunt Jumps (sauts acrobatiques), appuyez sur le stick droit pour consulter les chiffres par comté.
  2. Dans la carte du menu pause, ouvrez Exploration → Lieux de cascades pour les noms. Violet signifie découvert, blanc signifie terminé. Vérifiez l’entrée avant de refaire un saut déjà réussi.

Mile Zero Air Station Southeast

  1. Allez à Goose Key. À la bifurcation à l’est de la base, prenez la branche du bas pour rejoindre la clôture sud-est.
  2. Après les barricades, alignez-vous sur le monticule de terre vers la clôture. Gardez de la place pour accélérer et atterrissez dans l’aérodrome. Consultez le guide d’accès à Mile Zero avant d’entrer dans la zone interdite.

Les paires de sauts dans les Keys

  • Saltrock Bridge East / Saltrock Bridge West. Repérez les deux points de départ nommés sur l’ancien passage entre Abismo Key et Goose Key.
  • Key Lento Bridge East / Key Lento Bridge West. Cherchez sur l’ancien passage entre Abismo Key et Key Lento. Distinguez les deux départs grâce aux noms sur la carte.

Pour le défi bonus d’un pont, essayez les deux moitiés à la suite. Pour le compteur de progression, vérifiez chaque marqueur séparément.
