Comment saisir un code

  1. Terminez l’histoire et appuyez vers le haut sur la croix directionnelle en exploration libre pour ouvrir le téléphone du jeu.
  2. Sur PS5, maintenez L1 et appuyez sur R1. Sur Xbox, maintenez LB et appuyez sur RB.
  3. Saisissez les directions dans l’ordre. La séquence est identique sur les deux consoles.

Un code actif bloque les sauvegardes, trophées et succès pour cette session. Sauvegardez manuellement avant. Pour reprendre normalement, redémarrez le jeu et chargez cette sauvegarde.

Combien de médailles pour remplir les munitions ?

PC Gamer compte 20 médailles de bronze ou mieux, GamesRadar+ en compte 25. La séquence de touches est identique. Vérifiez le chiffre dans votre menu de progression.

Débloquer l’immunité aux chutes

PowerPyx et 3DM indiquent 20 chutes de 40 pieds auxquelles il faut survivre. Vérifiez après l’histoire. La séquence reste à confirmer.

Le code ne fonctionne pas

Vérifiez que l’histoire est terminée, que le code est débloqué et que vous êtes en exploration libre. Ouvrez l’accueil du téléphone avant les boutons supérieurs, puis recommencez toute la séquence. Pour une porte de mission, utilisez le clavier sur place.
