Les épreuves Top Fun Drones dans GTA 6

Gagnez une épreuve sur chaque site Top Fun pour le trophée. Pour les 100 % du mode Histoire, finissez les trois épreuves sur chacun des 14 sites.

Débloquer les trois épreuves

  1. Approchez du site jusqu’à voir l’icône bleue du drone. Sélectionnez-la dans Carte → Activités → Top Fun Drones. Prenez un bateau ou un aéronef pour Dalton Island.
  2. Lancez l’épreuve 1 et battez le temps cible. Faites de même dans l’épreuve 2 pour ouvrir le dernier parcours. Si vous dépassez souvent le temps cible, franchissez d’abord proprement les passages étroits avant de pousser le stick à fond en ligne droite.
  3. Terminez l’épreuve 3 en n’importe quel temps pour les 100 %. Vérifiez Progression → Activités → Top Fun Drones avant de partir. Vous devez avoir trois épreuves terminées sur chaque site, dont deux sous le temps cible.
