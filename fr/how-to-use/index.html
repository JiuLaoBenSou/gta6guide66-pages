Comment utiliser GTA 6 Guides

Devant le clavier du laboratoire

  1. Ouvrez la fiche du laboratoire dans Frais de labo.
  2. Vérifiez que vous êtes au laboratoire derrière le comptoir de Moonstone Boutique.
  3. Saisissez 0420 sur le clavier du jeu en commençant par le zéro.

Essayer un code de triche après l’histoire

  1. Gardez une sauvegarde manuelle avant d’essayer un code de triche.
  2. Ouvrez le guide de saisie des codes de triche et suivez les touches de votre console.
  3. Lisez les directions de la croix directionnelle de gauche à droite. Vérifiez la condition de déblocage à côté de la combinaison.

Garder une mission pour plus tard

  1. Ouvrez le guide de sauvegarde manuelle avant de commencer la mission.
  2. En exploration libre, ouvrez le menu de pause et choisissez Game → Save Game.
  3. Utilisez un emplacement distinct et vérifiez l’heure dans la liste. Choisissez Load Game pour revenir à ce point plus tard.
