Courses et défis de course dans GTA 6

Trouvez les six séries, débloquez les épreuves et vérifiez quels résultats comptent pour le trophée et les 100 % du mode Histoire.

Quels résultats comptent ?

  • Victoires en courses uniques. Gagnez 20 courses différentes pour Earn Cash, Not Kudos. Il en faut 30 sur 40 pour les 100 % du mode Histoire.
  • Médailles de défis de course. Il faut 10 médailles d’or sur 13 pour les 100 %. Les épreuves de chrono, de score et de cascades ont leur propre compteur.
  • Épreuves de drone. Consultez le guide de Top Fun Drones pour les 42 épreuves à part.

Débloquer les courses de rue et de circuit

  1. Courses de rue à Vice City. Après Came de choix, passez à Jason et lisez le message de groupe de Manuel. Lancez Join a Street Race à Salton.
  2. Gellhorn Raceway. Faites l’épreuve d’introduction (Introduction) pour ouvrir Keep It PG. Classez-vous dans les épreuves amateurs pour débloquer d’autres tracés. Sur PS5, le menu testé de Keep It PG acceptait une note routière de 500 à 780. Si votre voiture ne remplit pas la condition, prenez un véhicule de location du circuit.
  3. Thrillbilly Mud Club. Suivez l’objectif de Billy Check Out the Mud Club dans North Kelly County. Une fois les courses accessibles, choisissez une épreuve sur terre ou sur ovale au club.

Repérez les marqueurs bleus dans Carte → Activités → Courses. Approchez-vous en voiture si un marqueur manque. Si l’épreuve suivante reste verrouillée, terminez celle qui est disponible et consultez à nouveau le menu du site. Vos victoires figurent dans Progression → Activités → Courses.

Consultez le parcours des quatre missions de Yago pour Freeway Run, qui est limité dans le temps, et le rendez-vous au restaurant à Little Cuba.

Les 40 courses uniques

Hit ’N’ Run VC · 9

Lancez la course de Salton après Came de choix. D’autres départs se trouvent à La Perle, Ocean Beach et Gloriana Key.

  • Airport Run
  • Beach Blast
  • Freeway Run
  • Little Cuba Run
  • Mural Tour
  • Port Cruise
  • Rialto Run
  • Shoreline
  • The Tunnel
Animal Crackers · 8

Cherchez deux courses par lieu à Grayson, Redshaw’s, Ranchers et Big Pine.

  • Farm Tour
  • Golf Tour
  • Landfill
  • Log Jam
  • Mountainside
  • Red Canyon Run
  • Strip Mine
  • Wetlands Circuit
Gellhorn International Raceway · 11

Allez au circuit routier au sud de Port Gellhorn. Après chaque résultat, consultez le menu du circuit pour voir le tracé débloqué.

  • Basic Loop
  • Basic Loop CCW
  • Full Loop
  • Full Loop CCW
  • Intermediate Loop
  • Intermediate Loop CCW
  • Long Loop
  • Long Loop CCW
  • Short Loop
  • Short Loop CCW
  • Rallycross Loop
Boone Speedway · 2

Cherchez les départs de l’ovale et du circuit en huit au sud-ouest de Hamlet.

  • Figure 8
  • Oval
Ambrosia Raceway · 2

Approchez du circuit au nord d’Ambrosia pour ses deux épreuves de démolition.

  • Figure 8
  • Oval
Thrillbilly Mud Club · 8

Cherchez dans North Kelly County. Au chapitre 2, les missions facultatives de Billy vous y conduisent.

  • Big Mud
  • Dirt Slam
  • Figure 8 Blitz
  • Hog Hustle
  • Muck Scramble
  • Skid Loop
  • Sludge Rush
  • Trash Dash

Les 13 défis de course

Lancez une épreuve à son marqueur bleu. Vérifiez sur la fiche si l’or dépend du temps ou du score. Après l’épreuve, consultez la médaille dans Progression → Activités → Défis de course. Avec dix médailles d’or, vous pouvez laisser jusqu’à trois défis pour plus tard.

  • Ambrosia Raceway - Raceway Trial
  • Boone Speedway - Speedway Trial
  • Gellhorn Raceway - Dragway Trial
  • Gellhorn Raceway - Raceway Trial
  • Hamlet - BMX Stunt Run
  • Mount Kalaga - Cycling Trial
  • Thrillbilly Mud Club - Air Time Stunt Run
  • Thrillbilly Mud Club - Dirt Track Trial
  • Thrillbilly Mud Club - Drag Trial
  • Thrillbilly Mud Club - Hill Climb Trial
  • Thrillbilly Mud Club - Oval Trial
  • Thrillbilly Mud Club - Swamp Run Trial
  • Waning Sands - Motocross Stunt Run
